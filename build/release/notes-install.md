## Install

You need Neverwinter Nights: Enhanced Edition (Steam, GOG or Beamdog) on Windows 10 or 11, 64-bit.

- **Play:** unzip `OpenWinter-{version}-windows-x64.zip` anywhere and run `OpenWinter.exe`. It finds your game by itself.
- **Host a server:** unzip `OpenWinter-Server-{version}-windows-x64.zip` and run `openwinter-server.exe --module "<path to .mod>"`.

Each zip has a README.txt. Check downloads against `SHA256SUMS.txt`. See the [README](https://github.com/Ambitosis/OpenWinter#download-and-play) for details, and report problems on the [issue tracker](https://github.com/Ambitosis/OpenWinter/issues/new/choose).
