# P2P transit-time discriminator

Prepared, not measured. Five wholly authored Linked Fountain models hold life at
two seconds and vary only `combinetime`: 0, 0.25, 0.5, 1 and 2. All use selector 1,
zero velocity/gravity/Bezier handles and a direct reattachable reference child.
The native comparison must pass ten actor/model gates and all 26 framebuffer
images. No transit-time equation is inferred from the public parameter name.

Stock Flame has life 1 and combinetime 0.5; the existing targeted-stream fix
restores its route but does not yet implement or certify this parameter's timing.
