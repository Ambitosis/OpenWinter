# Door presentation

Run `python tools/visual/visual.py run doorlook --native-framebuffer --openwinter-args "--ui classic --visual-delay 0 --visual-audio 1"`.

The first three captures compare closed, open/unhovered and hovered transition
states. The native quick right-click on ordinary ground also issues movement;
the last two frames have different PC/camera positions and are not accepted as
equal-camera comparisons. Self-issued opening swing direction also differs.
See [door evidence](../../../../docs/DOORS.md).
